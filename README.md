# 幻海迷局 · 人间天讲记知识库（Agent Skill）

把 [Agent Skills](https://code.claude.com/docs/en/skills) 装进你的助手的佛学知识库。内容整理自**人间天（幻海迷局）** 2015—2026 年讲经、答疑、感应记合集，共 **6,360 篇 / 36.3MB**，包含**完整语料原文**，压缩为 17 个主题章 + 全量索引 + 速查表 + 引语可信度分级。

## 这是什么

一个**自带语料**的可按需加载 Agent Skill：AI 助手遇到佛学义理或修法问题时，只读相关的 1—2 个章节（约 3—4k token），需要原句时再去 `corpus/` 里定位行号回源——而不是把 36MB 全文塞进上下文。

```
SKILL.md                          入口：14 条核心框架 + 章节路由（约 11.8KB）
chapters/ch01—ch14                主线路径：回向/消业/债主/信愿行/学佛次第/忏悔/超度/读经…
chapters/ch15—ch17                经论路线：楞严经、法华经略说、小乘经典（新增，旧库全无）
corpus/总合集-全量.md              ★ 6,360 篇讲记原文（36.3MB），随仓库分发
article-index.md                  6,360 篇全量索引（日期｜系列｜主题标签｜行号｜标题）
glossary.md                       术语表（按原文用法，附频次）
patterns.md                       16 条可执行法门 + 排障清单
cheatsheet.md                     14 条红线 + 决策表 + 记忆锚点
quote-audit.md                    ⚠ 引语回源体检报告 —— 使用前务必先读
scripts/                          索引生成 + 引语校验脚本（语料在库内，零配置可跑）
```

## 安装

```bash
git clone https://github.com/huanhaimiju/huanhaimiju.git
cp -r huanhaimiju ~/.workbuddy/skills/          # WorkBuddy
# 或 ~/.claude/skills/（Claude Code）、~/.codex/skills/、.agents/skills/（项目级）
```

克隆约 36MB（H: 语料为 UTF-8 明文）。技能靠 `SKILL.md` frontmatter 的 `description` 被自动触发，也可直接说「按幻海迷局的说法，回向该怎么配比」。

## 核心主线（详见 SKILL.md）

1. **消业为王** — 修行停滞先回消业，不加大培福；消七七八八即可，不追百分百
2. **三位配合** — 定课 → 小回向 → 超度，缺一环另两环有裂隙
3. **小回向 = 利益分配** — 主体是**福德**非功德；债主 6 : 眷属 3 : 有缘 1
4. **债主事大** — 唯一不能靠佛菩萨圣力化解的干扰源；还债要平摊，集中还等于鼓励插队
5. **四种力** — 神力/业力 × 内外；内占 6/7，外占 1/7
6. **三渐次是硬次序** — 除助缘 → 刳正性 → 违其现业
7. **信之四等** — 理信 / 事信才拿得到，智信一生拿不到
8. **愿是唯一的内力**

## ⚠ 引语可信度分级（重要）

建库分两批完成，可信度不同：

| 章节 | 引语可信度 | 处理建议 |
|---|---|---|
| **ch15 / ch16 / ch17** | 100% 可回源 | 可直接作为作者原话引用 |
| **ch01—ch14** | 约 60% 为删节转述（相似度 ≥0.75，语义属实但非原句），另 155 处为概括表述 | 引用前**必须**用 `article-index.md` 定位行号回源核对 |

ch11 / ch13 / ch14 的「需核对」比例最高（57/5、29/31、49/20），属要点式 bullet 概括而非原句。逐章统计见 [quote-audit.md](quote-audit.md)。

语料已随仓库分发，校验脚本开箱即用：

```bash
python scripts/audit_all.py                                  # 全库统计（OK / REFORM / ABSENT）
python scripts/verify_quotes.py chapters/ch15-lengyan.md      # 严格模式，有未命中则退出码 1
python scripts/grade_absent.py 12                            # 对 ABSENT 片段做相似度分级
python scripts/build_index.py                                 # 重建索引
python scripts/build_index.py --corpus /path/to/其他语料.md     # 也可校验外部语料
```

用外部语料时设环境变量 `HUANHAI_CORPUS` 代替 `--corpus`。
